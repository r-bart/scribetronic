# Calendar

The editorial calendar for the writing system. One directory per ISO week (`<YYYY-WNN>/`), each owning its plan, its newsletter, and its derivatives. `rules.yaml` defines recurring slots; `history.md` is the append-only event log; `archive/` holds completed weeks.

## Layout

```
thoughts/writing/calendar/
├── README.md                    ← you are here
├── rules.yaml                   ← recurring slot rules
├── history.md                   ← append-only event log
├── index.md                     ← auto-generated overview
├── 2026-W18/                    ← one directory per ISO week
│   ├── plan.md                  ← the week's table (queued/drafted/published/skipped)
│   ├── newsletter.md            ← the long-form parent piece (drafted Sunday)
│   └── derivatives/             ← short-form pieces spun out from the newsletter
│       ├── mon-observation-<slug>.md
│       ├── tue-x-vs-y-<slug>.md
│       └── ...
└── archive/                     ← weeks where every row is published or skipped
    └── 2026-W17/
```

## Lifecycle of a week

1. **Scaffold.** `/agenda plan-week <YYYY-MM-DD>` creates `<YYYY-WNN>/plan.md` with 6-7 rows (1 newsletter + 5 derivatives), all `queued`.
2. **Draft the newsletter (Sunday).** `/write weekly-newsletter` saves to `<week>/newsletter.md` and flips its plan.md row to `drafted`.
3. **Repurpose.** `/write --repurpose` reads the newsletter, generates the derivative drafts under `<week>/derivatives/`, flips each row to `drafted`.
4. **Publish (daily Mon-Fri + Sun).** `/write-publish <slug>` moves the piece to `src/content/blog/` (newsletter) or `thoughts/writing/published/social/<platform>/` (derivatives), flips row to `published`.
5. **Archive.** When every row is `published` or `skipped`, `/write-publish` offers to move `<week>/` to `archive/`.

## Where to look for…

| You want to find… | Look at |
|---|---|
| The recurring schedule | `rules.yaml` |
| What's planned this week | `<current-week>/plan.md` |
| The pieces I'm working on | `<current-week>/newsletter.md` and `<current-week>/derivatives/` |
| What I've already done | `history.md` (chronological) |
| A piece I published months ago | `archive/<old-week>/` |
| A bird's eye view | `index.md` (regenerated by `/agenda show`) |
